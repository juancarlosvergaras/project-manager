Pulsa una tecla o un gesto de la perilla para cambiar lo que hace. Lo que ves es lo que el teclado tiene grabado.

    La tecla del micrófono se pone a Ctrl+Mayús+Alt+F15, una combinación que solo entiende este servicio, y con ella abre el dictado en el programa que elijas. La perilla queda como rueda del ratón: un giro hace rueda abajo, el otro rueda arriba, y pulsarla es el clic central. Si te desplaza al revés, cambia los dos giros entre sí.

    Las luces del teclado no se pueden cambiar

    Comprobado con el aparato: cada tecla tiene su color fijo en el firmware —azul el micrófono (encendido mientras graba), verde Sí, rojo No— y no obedece a nada de lo que se le grabe. El teclado acepta la orden de luces y la devuelve al releer, pero no cambia nada visible; el programa del fabricante esconde esta pestaña para este modelo por lo mismo. Lo de abajo se deja por si un firmware futuro lo atiende.

    A quién le hablas

    Al pulsar la tecla del micrófono, SikaiMini trae este programa al frente, pincha su cuadro de escribir y abre el dictado. Al volver a pulsarla, lo cierra y manda lo dictado.

    El micrófono del teclado

    El dictado de Windows escucha por el micrófono predeterminado. Para hablar desde lejos, ese tiene que ser el del teclado, que viaja con él por cable o por el receptor de 2,4 GHz.

    Cómo se comporta la tecla del micrófono

    Es un ajuste del propio teclado; se graba por cable.

    Con «pulsar», SikaiMini abre y cierra el dictado con cada pulsación. Es el modo recomendado.

    Atajos de dictado de cada programa

    Primero se pulsa el botón de dictado del programa por accesibilidad. Si no aparece, se manda su atajo de teclado. Vacío = no tiene.

    Clave del panel

    Sin clave, el panel solo se abre desde el propio equipo. Con ella se puede publicar en Internet.

    sikaimini.proyectoia.org

    Este equipo se presenta solo al portero del Mac mini por Tailscale y le abre un túnel: la dirección pública pasa al PC que tenga el teclado, sin publicar nada ni abrir puertos. Hace falta clave en el panel y Tailscale conectado.

    Dónde escucha el panel

    Solo en este equipo, o también en su dirección de Tailscale (camino de respaldo; ya no hace falta para la dirección pública). Desde el propio equipo nunca se pide clave.

    Si Windows pregunta si permite a SikaiMini en la red, di que sí: sin eso Tailscale no llega.

      Cómo se usa
      
    
        
      
      1. Conecta el teclado por cable una vez. SikaiMini le graba las tres teclas, la perilla, el modo del micrófono y, si has elegido unas, las luces. Después puede ir por el receptor de 2,4 GHz: todo funciona igual, solo que no se puede reconfigurar hasta volver al cable.
        2. 
      
      2. Elige a quién le hablas en la pestaña «Micrófono y dictado»: Claude, ChatGPT, Cursor o la ventana que esté activa.
        3. 
      
      3. Pulsa la tecla del micrófono. El programa se viene al frente y se abre el dictado. Habla.
        4. 
      
      4. Vuelve a pulsarla. Se cierra el dictado y se manda lo dictado con Intro (se puede quitar en «Afinar el dictado»).
        5. 
      
      5. ✗ y ✓ hacen Retroceso e Intro, como venían; se les puede poner cualquier otra cosa.
        6. 
      
      6. La perilla es la rueda del ratón: gira para desplazar la ventana que tengas delante y púlsala para el clic central. En la pestaña «Teclado y perilla» se le puede poner volumen, zoom (Ctrl + rueda) o cualquier tecla.
        7. 
    
      
    
      Este teclado lleva el mismo chip que el MiniMic y Windows los ve iguales. SikaiMini los distingue al leerlos —este tiene seis registros y aquel cinco— y no le escribe nada al que no es suyo.
      
  
      

      



      
  
      
    
      SikaiMini en otro PC
      
    
      El teclado se lleva a cualquier equipo, pero la tecla del micrófono la maneja este servicio, que tiene que estar en el PC que tenga el teclado cerca. Una carpeta con Python dentro: no hay que instalar nada antes.
      
    
      
      Descargar SikaiMini.zip
      
    
      
    
        
      
      1. Descárgalo, extrae la carpeta SikaiMini donde quieras tenerla y abre SikaiMini.exe. Hace la instalación guiada: crea la tarea que lo arranca con Windows y lo pone en marcha.
        2. 
      
      2. Si Windows avisa de «editor desconocido», elige «Más información › Ejecutar de todas formas»: no está firmado.
        3. 
      
      3. Abre http://127.0.0.1:8772 en ese PC. Conecta el teclado por cable una vez para que se le graben las teclas y la perilla.
        4. 
      
      4. Para que sikaimini.proyectoia.org pase a ese equipo cuando tenga el teclado, en Ajustes ponle clave y elige «Escuchar en» su dirección de Tailscale.
