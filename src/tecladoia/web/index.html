Seguir a la aplicación que uses

ChatGPT de escritorio y otros programas no avisan de lo que hacen, así que el teclado nunca sabrá si están pensando. Lo que sí puede es acompañarte: al cambiar de aplicación, cambia de modo, y con el modo cambian sus cuatro teclas y su pantalla. El patrón se busca en el nombre del programa y en el título de la ventana; gana la primera regla que coincida.

Usar TecladoIA en tu equipo

El Bluetooth no viaja por Internet: para hablar con el teclado de verdad, la aplicación tiene que correr en el ordenador que lo tiene cerca. Este panel puede estar publicado en un servidor, pero el teclado está donde estás tú.

El paquete es el mismo código que estás usando ahora, empaquetado al vuelo. Solo necesitas Python 3.10 o posterior.

Descargar la aplicación

Después de descargar

  1. Descomprime el archivo.
  2. Instala: pip install -e ".[ble]"
  3. Pon los enganches: tecladoia instalar
  4. Arranca: tecladoia servicio
  5. Abre http://127.0.0.1:8770
